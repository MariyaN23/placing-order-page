# Создание заказа

## Описание

Страница создания заказа с меню, главным баннером, формой для размещения заказа и футером.


## Функционал
1) Главное меню - десктопная и мобильная версии. Header прилипает к верху страницы при скролле.
2) Баннер с большой картинкой, видной на десктопах
3) В форме оформления заказа есть:
   - Кастомный селект, чтобы одинаково выглядел на всех браузерах (в т.ч. мобильные)
   - Стилизованные инпуты для email, текстового значения и выбора диапазона
   - Кнопка выбора файла
   - Валидация браузером на проверку пустых значений и валидного email
   - При отправке формы - алерт и очистка всех инпутов
4) В футере платежные системы не ссылки, а контакты - ссылки
